# Arquitectura de Sistemas de Inteligencia Artificial

## Descripción
Este repositorio corresponde a la materia **Arquitectura de Sistemas**.
Aquí se documentan conceptos básicos relacionados con la estructura, componentes y funcionamiento
general de sistemas basados en inteligencia artificial.

## Objetivo
- Comprender la arquitectura general de un sistema de IA
- Identificar los componentes principales de sistemas de aprendizaje automático y deep learning
- Aplicar buenas prácticas básicas de documentación con GitHub

## Contenido del repositorio
- README con información general del proyecto
- Archivos y evidencias relacionadas con las actividades de la materia

## Tecnologías
- Git y GitHub
- Python (cuando aplique)
- Herramientas básicas para desarrollo de IA
